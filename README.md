# Melvin Andrea — Portfolio V2

Personal portfolio website built to showcase my work in frontend development, mobile development, UI/UX design, photography, videography, and visual editing.

This is the second version of my portfolio, rebuilt from a static HTML/CSS/JavaScript website into a modern React + TypeScript application with a reusable component architecture.

---

## ✨ Overview

Portfolio V2 focuses on combining development and creative work into one interactive digital portfolio.

The website showcases:

- Frontend & mobile development projects
- UI/UX design projects
- Photography
- Graphic design
- Short movies
- Video editing
- Certificates and achievements
- Development tools and technologies

The design direction focuses on a dark, minimal, glassmorphism-inspired interface with subtle gradients, interactive elements, and smooth motion.
